# Agriculture Data Analysis Project

## Project Overview
This project focuses on cleaning and analyzing agricultural data and creating an interactive dashboard to present key insights.

## Tools Used
- Microsoft Excel (Data Cleaning)
- Microsoft Power BI (Dashboard Creation)

## Files Included
- Agriculture_Raw_Data.csv
- Agriculture_Cleaned_Data.xlsx
- Agricultural Dashboard.pdf
- Dashboard_Screenshot_1.png
- Dashboard_Screenshot_2.png

## Project Process
1. Imported the raw agricultural dataset.
2. Cleaned and prepared the data using Microsoft Excel.
3. Built an interactive dashboard in Microsoft Power BI.
4. Exported the dashboard as a PDF and screenshots.
